# Original Phase 1 instruction package

[`instruction-package.zip`](instruction-package.zip) retains the 74 distributed files of the
user-supplied `ascension-workflow-phase1-package` version 1.0.0. Every original file's bytes are
unchanged. The archive excludes generated `__pycache__` directories and personal paths.
[`provenance.json`](provenance.json) records the original manifest/checksum hashes and archive hash.

The package is original user-supplied instruction material whose launch explicitly authorizes
copying it with provenance. It has no separately supplied license; it is retained privately,
without relicensing or a claim of permission for public redistribution.

Extract it in an approved local scratch directory and read `00_START_HERE.md` followed by
`01_MASTER_ORCHESTRATION_PROMPT.md`. Configuration fragments are inert examples and must not
be installed automatically. The archive's Python programs verify the instruction package only.
They are not active tooling for this repository or evidence of a gameplay workflow implementation.

The live records in this repository intentionally differ from the package's untouched templates.
Use the live execution state when resuming; preserve the original package for provenance.
The requirement assertions, fault cases, task descriptions and template fields copied into the
live ledgers have the same imported provenance; original execution annotations do not relicense
that imported text. Source mappings are recorded in the provenance document.
